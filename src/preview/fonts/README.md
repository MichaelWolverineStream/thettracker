# Timer Fonts

Latin, normal-style WOFF2 files from the Fontsource 5.3.0 npm
distributions. Original license texts are included alongside each font.
All six fonts are licensed under the SIL Open Font License 1.1.
The three monospace faces use weight 700. Bungee, Audiowide and Monoton use
their native 400-weight outlines, registered for weights 400 through 700 so
the timer's existing bold styling does not synthesize extra strokes.

The landing page and preview tracker load these files from the same deployment.
The legacy tracker does not import them. The Current option retains the original
inherited font stack and does not select a bundled font.
